# PakKom Exambro V5.2.3

Perbaikan khusus Keluar Darurat siswa.

## Yang diperbaiki
Dialog pilihan alasan tidak lagi memakai radio list Android.
Sekarang alasan selalu ditampilkan sebagai tombol besar:
- Aplikasi/halaman bermasalah
- Koneksi bermasalah
- Perangkat bermasalah
- Atas arahan guru
- Lainnya

Setelah salah satu alasan dipilih:
1. muncul konfirmasi kedua,
2. `stopLockTask()` dijalankan,
3. fullscreen/immersive dipulihkan,
4. perangkat diarahkan ke Home,
5. Exambro ditutup.

Fitur lain tetap:
- Refresh halaman
- Cek koneksi
- Info aplikasi
- Akses Guru + PIN 2468
- Session Recovery
- Connection Recovery
- Safe Finish dari web
