PAKKOM EXAMBRO V5.1 — CARA UPLOAD KE GITHUB

1. Ekstrak ZIP ini.
2. Buka repository Android Anda: pakkom-exambro-android.
3. Upload SEMUA ISI folder PakKomExambroV5.1 ke ROOT repository.
   Jangan upload folder pembungkusnya jika ingin build langsung.
4. Pastikan struktur root GitHub menjadi:
   .github/workflows/build-apk.yml
   app/
   build.gradle.kts
   settings.gradle.kts
   gradle.properties
   README.md
5. Commit/push.
6. Buka GitHub > Actions.
7. Pilih "Build PakKom Exambro V5.1 APK".
8. Klik Run workflow.
9. Jika hijau, download artifact:
   PakKom-Exambro-V5.1-APK
